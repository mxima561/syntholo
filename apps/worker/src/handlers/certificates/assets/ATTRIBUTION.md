# GNU Unifont certificate renderer fonts

The certificate renderer bundles unmodified GNU Unifont 15.0.04 TrueType files:

- `unifont-15.0.04.ttf`
- `unifont_upper-15.0.04.ttf`

Source: `https://ftp.gnu.org/gnu/unifont/unifont-15.0.04/`.
